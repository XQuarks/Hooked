#### 🟡 第二批 B 组：**必须先定方案**（会动数值或玩家能感知的结构）

**A2 枪店解锁节奏 —— 建议提到本批第一位（B10 之后）。**

- **实测背景**：枪械是最大的金币出口（七把买齐升满 **2,601,172**），
  而它**开局全部可见、只有价格闸门**。首图玩家可支配的金币是 **24,907**
  （14,907 渔具店 + 10,000 船票），而**一把散弹枪"买入 + 升满"就是 134,451**。
  → 首图玩家一旦开始买枪，**换图会被明显推迟，而他得不到任何提示**。
- **注意**：原来 A2 的判据写的是"会拖慢'潜到底'和'图鉴 75%'两个换图条件"——
  **图鉴门槛已在 v0.7 第二批删除**，所以理由要换成上面这条（钱被抢走）。
- **候选方案（三选一，我倾向 ②）**：
  1. 给枪加 `unlockMap`（跟渔具店同一套机制）：第 2 张图才上架 3 把强力枪；
  2. **按深度锚定**：枪店照旧全可见，但把"买不起"换成"**还没到那个深度**"——
     例如加特林 / 鱼叉 / 激光 / 巴雷特分别在潜到 **300 / 500 / 700 / 900m** 时上架。
     好处是**引导玩家先潜深**，与"换图要潜到底"同向；成本是枪店需要新状态；
  3. 不动解锁，只在枪店加"当前推荐"标记（最轻，但治标不治本）。

**A1b 货架感（补便宜的中间档）。**

- **实测**：首图货架 **4 行，价格 160 / 200 / 250 / 300 —— 全在同一个档**
  （v0.5 之前有"基础 / 进阶"两档，现在分层被锁到第二张图去了）。
- **候选**：① 补 1~2 项**低价中间档**（150~400 的新升级项）；② 把「鱼护 / 鱼饵」的
  **第一段（Lv0~2）提前到首图**开放，剩下的留到第二图。
- ⚠ **这一项直接和 A11 抢钱**：首图多一个出口 = 主线更短（§4.6 结论 4）。
  所以要拍板的其实是"**用内容量换货架感**划不划算"。
