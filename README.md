## 玩法（三段式循环 · 已反转）

打开页面先看到**渔夫在船上待机**的画面（船随小波浪缓缓摇晃），
屏幕上方是**当前钓鱼地图的名字**（固定显示「宁静海湾」，不随等级变化），
下方是**你在这张地图里已经探索到的最深处**。
**点击屏幕**才抛竿，也可以点左下角 **📱 手机** 打开手机，在里面的 **App**（电话 / 渔具店 / 枪店 / 图鉴 / 航线 / 设置，**船厂**要等船厂老板打来电话才出现）里接电话、升级、买枪、看图鉴、换图、买船、改设置。

| 阶段 | 你要做的事 | 操作 |
|---|---|---|
| ① **抛竿** | 鱼钩从竿梢被甩到空中划一道抛物线，**在空中就能左右移动它、决定落点** | 点屏幕抛竿，然后左右拖动 |
| ② **下沉** | **躲开鱼** —— 碰到鱼鱼线就被扯住、自动收线，这一竿到此为止 | 左右拖动屏幕 |
| ③ **上升** | **主动去碰鱼** —— 上升阶段碰到的鱼才会被勾住，这才是渔获 | 左右拖动屏幕 |
| ④ **天空** | 渔获按身价飞向高空、**边飞边翻滚**，用**当前装备的枪**把它们打下来；没打死的会**被再顶飞一段** | 点按 / 长按（看枪） |
| ⑤ **手机 · 渔具店** | 用金币升级 6 项装备 + 买断 1 件工具（手机里的 App） | 点按 |
| ⑥ **手机 · 枪店** | 买枪 / 换枪 / 给枪升级（7 把枪，每把 5 级） | 点按 |
| ⑦ **手机 · 图鉴** | 查看 38 种鱼的资料卡（含血量），没钓到过的只有黑色剪影 | 点按 |
| ⑧ **手机 · 航线** | 换一片海：**钓到极地海图 + 有一艘船**（两样齐了才能去） | 点按 |
| ⑨ **手机 · 设置** | 音效开关 / 清空存档 / 收起手机 | 点按 |

> **注意方向反过来了**：原作是"下沉碰鱼、上升躲鱼"，本作是"**下沉躲鱼、上升碰鱼**"。
> 下潜时鱼是障碍，上升时鱼才是奖励 —— 上升阶段从"屏息祈祷"变成了"主动横移扫鱼"。

**主界面大标题固定是地图名**（「宁静海湾」）：地图是比海域更高一层的结构，
一张地图里包含若干层海域（阳光浅滩 → 蓝色回廊 → 幽蓝深谷 → 无光深渊 → 海沟尽头）。
标题下方一行显示**你在这张地图里探索到的最深处**（还没下潜过就显示 `可下潜至 −860m`）。
标题字号在 90px 上下（`min(93px, 21vw)`），深海色的副标题带青色辉光、没有黑底。

**开局的 UI 是"长出来"的**：右上方深度读数在待机时完全隐藏，抛竿后淡入；
左侧深度尺从屏幕左侧滑入、右侧渔获面板从右侧滑入，都是 `cubic-bezier(.22,1,.36,1)` 的缓出。

**收线上拉有预备动作**：不管是撞鱼被迫收线，还是鱼线放到最长准备上拉，
鱼钩都会先**再往下探 13 米**（0.42s 缓动），同时屏幕提示 `即将上拉 ▲` / `碰到鱼了 · 即将上拉`。
给你一点"要起飞了"的心理准备，也让节奏不那么突兀。

**水下两条深度线**：左侧深度尺上一直画着两条线 ——
红色虚线 `鱼线 −240m` 是你**最多能潜到哪**，金色游标 `已潜 −135m` 是**这一竿已经潜到哪**。
顶部也有 `135 / 240m` 的读数，一眼就能看出离极限还有多远。

**风险要素 · 扣钱鱼**：首图「宁静海湾」里有 **3 种扣钱鱼**（第二张图还有第 4 种「冰水母」），一眼就能认出来 ——
暗红色描边、身上罩着一圈**脉冲红光晕**、头顶挂一个**始终正对镜头的 ⚠ 徽章**。

| 扣钱鱼 | 出现海域 | 惩罚 |
|---|---|---|
| 🐡 **河豚** | 阳光浅滩 | −30 金币，清空连击 |
| ⚡ **电鳗** | 蓝色回廊 / 幽蓝深谷 | −30 金币，清空连击 |
| 🦁 **狮子鱼** | 幽蓝深谷 / 无光深渊 | −30 金币，清空连击 |
| 🪼 **冰水母**（冰封极地） | 浮冰浅海 | −30 金币，清空连击 |

> 罚款是**固定值**（`TUNING.pufferPenalty` = 30 金币）。
> ⚠ v0.5 起「保险」升级项已删除，罚款**没有减免路径** —— 撞上就是全价。
> 几种扣钱鱼的差别在**出现海域和体型/速度**，不在罚多少钱。

**扣钱鱼很罕见**（迭代 6 调过）：抽签权重只有普通鱼的 **25%**（`HAZARD_SPAWN.weightScale = 0.25`），
而且**每层海域最多只生成 1 条**（`maxPerZone = 1`）—— 超出上限就退回普通鱼池重抽。
按游戏里的实际抽签逻辑离线仿真（每层 20 万竿、含鱼群）：每竿期望只遇到 **0.10 ~ 0.29 条**，
占全部生成鱼 **约 3.5%** —— 同一仿真里把 `weightScale` 换回 1 且不封顶是 **0.35 ~ 1.01 条 / 12.5%**。
两个参数都在 `config.js` 里，想再调更容易或更稀有改这两个数就行。

打中飞过的海鸟额外 +60。
**连击**：每 3 连击 +0.25 倍率，最高 3 倍。

**鱼很少**：每层海域只有 **3~4 条**鱼（`FISH_DENSITY = 0.18`，把基准 92 条压到 18 条；
另有约 1/3 概率整层刷出"一群同种鱼"，那一群是**额外叠加**的），而且全部生成在鱼钩够得到的横向范围内。

**深度分区**（宁静海湾）：阳光浅滩 → 蓝色回廊 → 幽蓝深谷 → 无光深渊 → 海沟尽头，
越深鱼越值钱（6 → 680 金币/条），共 **20 种鱼**，各有独立 3D 造型、**独立血量（2 ~ 120 点）**与游动行为。

**冰封极地**（第 2 张地图，1240m）：浮冰浅海 → 霜蓝水道 → 极光长廊 → 永冻深渊 → 极夜之底，
**18 种**极地鱼（最贵 1900 金币），带极光 / 冰柱 / 头顶冰凌 / 浮冰障碍 / 鱼群 / 四档稀有度。

> **地图 vs 海域是两套概念**：**地图**是最高层级，一张地图里包含若干层**海域**。
> 当前两张：**宁静海湾**（860m / 5 层 / 20 种鱼）与**冰封极地**（1240m / 5 层 / 18 种鱼）。
> 主界面大标题显示的是**地图名**，图鉴按「地图 → 海域」两级分组。
> 加新地图只要往 `config.js` 的 `MAPS` 里追加一项，并在 `ZONES` 补上它的海域即可。
>
> ⚠️ 深度分区的查询**必须带地图**（`zonesOfMap(mapId)` / `zoneAtDepth(y, mapId)`）——
> 两张图的表层都在 0~70m，不带 map 的话在极地 −30m 会查到「阳光浅滩」。
>
> 每个海域有两个名字：**短功能名**（`name`，表层 / 中层 / 深层 / 深渊 / 海沟 —— 左侧深度尺上空间窄，
> 用它）和**雅称**（`nick`，阳光浅滩 / 蓝色回廊 / 幽蓝深谷 / 无光深渊 / 海沟尽头 ——
> 图鉴与文案里用它，更有地名感）。
>
> ⚠️ 注意：海域的雅称（`nick`）**不能和地图名重名** —— 迭代 6 就把 `ZONES.deep.nick`
> 从「宁静海湾」改成了「**幽蓝深谷**」，否则图鉴里会出现「宁静海湾 · 宁静海湾」。

**越深越黑**：画面随深度渐暗，两侧滑过岩石 / 海带 / 神秘光球与遗迹。
**灯具**升级决定你能看清多深 —— 365m 处不装灯具已经相当暗（暗度 **0.39**），
灯具满级能把暗度压到 **0.06**；鱼钩点光源强度 `0.47 → 2.84`（Lv0 → Lv20），
照射距离 `176.8 → 1795.2`（= 照亮半径 × 3.4）。

> 完整的深度 / 暗度 / 光源对照表见 [`docs/04-物理与经济.md`](./docs/04-物理与经济.md)。

**身价决定高度**：起飞初速 `v0 = 240 + √价值 × 14`，最高点 `v0² / 120`（空中重力取 60）。
所以最小的沙丁鱼只能蹿到 **627m**，而黄金鱼王能飞到 **3051m —— 一路飞进太空**，
第二张图的 Boss「极夜之王」更是能飞到 **6000m 以上**。

> 📊 逐种鱼的起飞曲线、滞空、水平漂移，以及镜头 / 翻滚 / 刹停的全部参数：
> 见 **[`docs/04-物理与经济.md`](./docs/04-物理与经济.md)**（自动生成）。

镜头锁定**最低的那条非扣钱鱼**（= 最快落回水里、最该先打掉的），把它放在**画面正中**
并把视野推近到 `0.70`；它被击落 / 落水后自动换下一条，天然形成"逐个点杀"的节奏。

**血越厚，越耐打**：每条鱼的血量写死在鱼种表里（**2 ~ 120 点**），一枪打不死的话它会**被爆炸再顶飞一段**——
补一段上冲初速 `148 + 剩余血量 × 12`（**超过 16 点血之后不再多顶**，否则血牛会一枪飞出大气层），
同时弹字告诉你 `还差 N 枪`。
所以那条 60 血的黄金鱼王不是一枪能拿下的，得追着它一路打到外太空；
第二张图的 Boss「极夜之王」更是 **120 血**。

**渔获在天上翻滚**（迭代 6 加强）：起飞时鱼会**三轴翻滚**，Z 轴（画面内打滚）是主轴，
初速 `±(7 + rand×9)` rad/s —— 一秒至少转一圈，比改前明显更疯。
X / Y 轴各给 ±3.5 / ±4.5 rad/s 的小幅陪衬，所以看起来是"在 3D 里翻"，不是平面转圈。
**中弹没死会被转得更快**：`knockUp()` 沿着当前旋转方向再叠一段角速度（不反向），
实测从 15.16 提到 28.74 rad/s —— 血越厚、越难打的鱼，被顶飞时转得越疯。

> 正交侧视相机下，**绕相机朝向轴（Z）的旋转才是"看得见在转"的那一个**。
> 只转 X 或 Y 的话，鱼在画面里只是"变扁一点"，几乎读不出旋转。

**只剩河豚就直接结算**：如果天上活着的鱼全都是扣钱鱼（打它只会扣钱），
它们**跳出屏幕外的那一刻就收竿结算**，不用干等到 26 秒的超时兜底。

**背景随高度变化**：海面 → 高空 → 平流层 → 中间层 → 近地轨道 → 深空。
云逐渐淡出、星空逐渐亮起、月亮从身边掠过，飞到最高处只剩星星和星云。

## 手机（电话 / 渔具店 / 枪店 / 图鉴 / 航线 / 设置都在里面）

待机界面左下角是**一部小手机**（v0.7 起：机身 + 屏幕 + 听筒 + HOME 条，不再是"图标 + 文字"）。
点开后游戏画面上浮出一个**巨大的智能手机**界面
（500×837 视口下实测 360×780，正好是 9:19.5 的现代竖屏比例），
渔具店 / 枪店 / 鱼图鉴 / 航线 / 设置五个入口全部搬进了手机里，做成 App 的样式与交互。

```
┌─────────────────┐
│  ●●●  12:13  ▮▮ 📶 🔋│  ← 灵动岛 + 状态栏（时钟 / 信号 / Wi-Fi / 电量）
│ ┌─────────────┐ │
│ │ 宁静海湾     │ │  ← 桌面小部件：地图名 + 探索进度 + 金币
│ │ 已探索至 −90m │ │
│ └─────────────┘ │
│  🛒   🔫   📖   🧭  │  ← 桌面 App 网格（5 个，第二行 1 个）
│ 渔具店 枪店 鱼图鉴 航线 │
│      ⚙️         │
│     设置         │
│                 │  ← 底部没有「抛竿」按钮：收起手机后点游戏画面才是抛竿
│  ▁▁▁▁▁▁▁▁▁▁▁▁  │  ← Home 指示条
└─────────────────┘
```

| 位置 | 内容 |
|---|---|
| **状态栏** | 实时时钟 + 信号 / Wi-Fi / 电量（全是内联 SVG 图标） |
| **桌面小部件** | 当前地图名 + 探索进度 + 金币余额，和主界面大标题同一份数据 |
| **桌面 App** | **渔具店**（金色）/ **枪店**（暖红）/ **鱼图鉴**（蓝色）/ **航线**（冰蓝）/ **设置**（灰色），圆角方块图标 |
| **App 视图** | 独立标题栏（`渔 具 店`）+ 返回键，打开时桌面让位 |
| **设置 App** | 音效开关（写入存档）/ 清空存档（带二次确认）/ 收起手机 |
| **航线 App** | 每张地图一张卡：**两个条件**（钓到海图 / 有一艘船）全绿才能开过去 —— 条件由  给出，界面只渲染 |
| **枪店 App** | 每把枪一张卡：机制说明 + 三四个数值的「当前 → 下一级」+ 购买 / 装备 / 升级 |

**三个交互细节**：

- **手机不占用玩法状态**：开着手机时游戏世界照常渲染（船照常摇），`state` 始终是待机 ——
  手机只是一层盖在上面的外壳，不是"另一个界面"。
- **手机开着时点游戏画面不会误抛竿**；点手机外的空白区域收起手机、恢复主界面入口按钮。
- **手机里没有抛竿入口**（v0.4.1 移除了底部那条常驻 Dock）：
  抛竿的唯一路径是**收起手机 → 点游戏画面**。手机是"船上掏出来看的东西"，
  从里面直接开钓会让"我在看手机"和"我在钓鱼"两个状态糊在一起。

## 电话引导（v0.6）

**渔具店的老王和枪店的阿海会给你打电话。** 他们不会教你钓鱼，只会在**你刚好需要知道某件事**
的时候打过来 —— 然后把你直接送到该去的地方。

| 什么时候打来 | 谁 | 说什么 |
|---|---|---|
| 第 **3** 竿之后 | 渔具店 · 老王 | 该买第一项升级了 |
| 鱼线升到 **Lv2** | 渔具店 · 老王 | 铅坠下面那个「直达深度」开关怎么用 |
| 潜到 **240m** | 枪店 · 阿海 | **打不动的鱼要升级枪** —— 渔具店里没有"攻击力"这一项 |
| 第 **25** 竿之后（且已去过极地） | 渔具店 · 老王 | 绞盘（一次性买断）能让你收线快 3 倍 |
| 潜到 **390m** | 枪店 · 阿海 | 深层血牛的两种解法：把枪升满，或者换巴雷特 |
| 去过**冰封极地** | 渔具店 · 老王 | 新海域的鱼更硬，别忘了枪店 |

**它是怎么表现的**：

- 手机响了 → **左下角那部小手机左右晃动**（金色描边 + 一圈扩散的光环），
  同时**屏幕上方滑入一张 iPhone 式来电卡**：圆形头像 + 来电人 + 「来电中…」+ 挂断 / 接听两个圆钮（v0.7）。
- 手机桌面上的**「电话」图标挂一个红点**（和真手机一样）。
- 点**来电卡**或那部小手机 → **直接进来电界面**，不用自己在桌面上找「电话」App；
  卡片上的两个圆钮分别是**忽略 / 接听**（忽略只是收起来，不记为已听 —— 抛下一竿回待机它还会响）。
- 对话**一句一句出**（点「继续」推进），读完出现「挂断 / 去 渔具店」两个按钮。
- 点「去 渔具店」→ **当场跳到渔具店**。这是"引导"和"告知"的分界线 ——
  只说一句"去枪店看看"然后让你自己找，多数人不会去。
- 听过的电话都记在**「电话」App 的通话记录**里，可以回看。
- ⚠ 来电卡**不是全屏遮罩**，卡片以外照样能点画面抛竿（真机是全屏，这里刻意不抄）。

> **四条硬约束**（破一条这套系统就变成噪音）：
> ① **只在待机（船上）时响**，绝不打断进行中的一竿；
> ② **每通只响一次**，听完永远不再响（弹窗会重复，电话不会）；
> ③ **两通之间至少隔 4 竿** —— 你可能在第 5 竿就连着满足三个条件，不隔开会一次收到三通；
> ④ **响铃不阻塞任何操作** —— 想无视就无视，照样能点画面抛竿。

## 升级（6 项有等级 + 1 项一次性工具）

渔具店是**手机里的一个 App**（待机界面左下角 📱 手机 → 渔具店）。
6 项装备能升到 **Lv20**，成本按 `base × 1.62^lv` 递增；绞盘是**一次性买断**。
**买完原地刷新**：不跳出手机、不整层重建，滚动位置和手机壳都不动。

> ⚠ **v0.7：首图是"新手图"** —— 货架上只有 **4 项基础**（鱼线 / 鱼钩 / 铅坠 / 灯具），
> **鱼护 / 鱼饵 / 绞盘**都要**到过「冰封极地」**之后才上架（显示成「未解锁」）。
> 而且**进度条只画本图这一段**（首图 5 格，不是 20 格）：每片海只开一段，
> 看不到"后面还有 15 格永远点不亮"的灰条。
> 老存档里已经买过这些项的玩家不受影响：**已拥有的项不会被判成"未解锁"**。

| 梯度 | 升级项 | 效果 | Lv0 → Lv20 |
|---|---|---|---|
| 基础 | 🎣 **鱼线** | 最大下潜深度 | 320 m → 2200 m |
| 基础 | 🪝 **鱼钩** | 上升阶段的捕获判定半径 | 8 → 24 |
| 基础 | ⚓ **铅坠** | **直达深度**：开竿可跳过的最大深度 | 80 m → 1540 m |
| 基础 | 🔦 **灯具** | 深海照亮半径 | 52 m → 528 m |
| 进阶 | 🧺 **鱼护** | 一竿最多串几条鱼 | 8 条 → 60 条 |
| 进阶 | 🐟 **鱼饵** | 本层高价鱼出现率 | 0% → 100% |
| 工具 | ⚙️ **绞盘** | **快速回收**：上升阶段多一个加速按钮（**到过冰封极地后上架**） | 一次买断 |

> 上表数值与商店里显示的**完全一致**，唯一来源是 `config.js` 的 `LEVELS` 曲线（改数值只改那里，
> 表里改了、文案和判定会自动跟着走）。
> 📊 **完整 21 级曲线、逐级成本、累计投入**见 **[`docs/03-升级与成本.md`](./docs/03-升级与成本.md)**（自动生成）。

**铅坠 · 直达深度**（v0.5 重做）：渔具店里铅坠那一行**下面挂着一个开关** ——
打开之后，开竿落水时钩子**直接出现在你指定的深度**，省掉从水面沉下去的那一段。
目标深度用 `−` / `+` 调，上限取三者之小：**铅坠等级、鱼线极限、鱼线极限的 70%**。

> **为什么卡 70%**：不卡的话，铅坠升满就等于把整个下潜阶段删掉 ——
> 而"下潜躲鱼"是这个游戏三段循环里的第一段。卡住之后，**每一竿至少还要自己下潜 30%**。
> 另外跳下去之后有 0.45 秒的**落地缓冲**（不判撞鱼）：鱼是开竿那一刻才刷出来的，
> 你是"盲选深度"，一落地就撞鱼属于运气，不该由你承担。

**绞盘 · 快速回收**（v0.5 重做）：买下之后，**上升阶段**右下角多一个青色的「快速回收」按钮，
按一下把收线速度乘 **3** 直到出水（按过之后按钮变灰，本竿不能再用）。

> 它是**你主动触发**的，不是自动的：上升阶段串鱼是主要收入来源，
> 无脑加速会让你一路跳过鱼群 —— 加速必须是一个"我现在够了"的决策。
> 这也是它值得买（省时间）但不会让玩法退化（少抓鱼）的原因。

**每张地图有自己的等级闸门**（`MAP_LEVEL_CAP`）。在当前地图买满后按钮会变成
「本图满级」—— 那就是"该换一片海了"的信号。目前两张图：**宁静海湾**闸门开在 **Lv5**（860m）、
**冰封极地**开在 **Lv9**（1240m）。（`MAP_LEVEL_CAP` 后面还留着 Lv13 / Lv17 / Lv20 三个节点，
对应熔岩海沟 / 废弃沉船 / 深海之声 —— 那三张图还没做。）

> **下潜时的撞鱼判定是固定值（8.4）**，不随鱼钩升级变大 ——
> 否则升级鱼钩会让你下潜更容易被迫收线，等于花钱买罪受。
> 鱼钩升级只负责让**上升阶段**更好抓鱼。
> ⚠ v0.5 起「加固」已删除，所以下潜的难度**完全由走位决定**，没有"花钱缩小判定"的出口。

**鱼护满了：不再挤掉任何一条，直接加速收线**（v0.7 改的口径）：

老口径是"挤掉最早串上的那条"，理由是"制造取舍"——但实际体验是**负反馈**：
玩家明明碰到了鱼，却看着一条已到手的鱼飞走，还要一直数着"还剩几条"。
现在改成 **串满 = 该出水了**：满了不再收新的、也不丢旧的，**自动把收线速度拉满**，
浮字提示「鱼护满了 · 自动收线」，本竿只提示一次。
（它和"上升途中撞鱼不会掉鱼"是同一条规则的两面 —— 已经串上的鱼**永远不会丢**。）

## 枪械（7 把 · 每把可升 5 级）

天空阶段用什么打鱼，由**当前装备的枪**决定。枪在**手机 → 枪店**里买、换、升级。

开局只有一把**普通手枪**：单点射击（**不支持长按连发**）、攻击间隔 **0.30s**、
爆炸半径 **24** —— 这个半径是旧版（48）的**一半**，刻意收小了，
让"范围"变成后面几把枪才有资格谈的东西。

| 枪 | 机制 | 价格 | 一句话 |
|---|---|---:|---|
| **普通手枪** | 单点（点一次一发） | 初始拥有 | 范围最小，但指哪打哪、没有空窗 |
| **散弹枪** | 单点 · 一次 6 颗弹丸扇形铺开 | 8,000 | 覆盖极广，单颗伤害低，贴脸才打得满 |
| **Uzi** | 长按连发 → 打空自动换弹 → 接着连发 | 14,000 | 爆发高，但有换弹空窗 |
| **加特林** | 长按持续连发（无弹匣） | 26,000 | 头 0.9 秒转速没上来，射速只有一半 |
| **鱼叉枪** | 单点 · 一条贯穿整屏的直线 | 34,000 | **线上的鱼全部命中**，排成一列时最爽 |
| **激光枪** | 长按持续照射，**越照越疼**（最多 ×5） | 42,000 | 连照过热后强制冷却 |
| **巴雷特** | 单发 · 伤害和范围都是全场最高 | 60,000 | 1.3 秒才能再开一枪 |

- 每把枪可升 **5 级**（Lv0 → Lv5），逐级提升自己的伤害 / 范围 / 射速 / 弹匣。
- 射击阶段底部会出现**枪械条**：枪名 + 等级 + **伤害/发**（连发枪显示弹匣 `7 / 9`，激光显示当前递增倍率）。
- ⚠ **v0.5：「攻击力」升级项已删除**，攻击力成长**并进了每把枪自己的伤害曲线** ——
  每把枪的伤害都乘了一条 `1 + 2.8·i/5` 的斜坡（Lv0 不变、Lv5 ×3.8），
  所以"把枪升满"的终局强度和删掉攻击力之前**完全一致**。
  想变强就**买更好的枪 / 把枪升满**，不再有第二条并行的攻击力轴。

## 图鉴（38 种 · 血量最高 120）

**手机里的一个 App**（待机界面左下角 📱 手机 → 鱼图鉴）。
有未读消息时左下角的**小手机会亮红点**（新枪上架 / 有没接的来电），点开手机能看到是哪个 App 在响。
迭代 6 之后图鉴是**「地图 → 海域」两级分组**：

- **第一级 = 地图**（**宁静海湾** 20 种 / **冰封极地** 18 种，各带地图描述与收集进度）
- **第二级 = 海域**，按深度从浅到深（如宁静海湾：阳光浅滩 → 蓝色回廊 → 幽蓝深谷 → 无光深渊 → 海沟尽头）
- 同一层海域里再按**身价升序**

还没去过的地图会显示成一个**未解锁的盒子**（「海域尚未抵达 · 打开手机里的「航线」App」），
不剧透里面的鱼。

海域标题用和游戏里**同一套雅称**，功能名只作为副标签跟在后面
（`阳光浅滩 ← 表层海域 · SUNLIT`），免得同一片海在标题页和图鉴里叫两个名字。
「所在海域」显示为 `地图名 · 海域雅称`（例如 `宁静海湾 · 阳光浅滩`）。
顶部有一行 `已收集 N / 38` 的总进度。每条鱼一张卡片：

| 状态 | 卡片内容 |
|---|---|
| **已钓获** | 彩色鱼图 + ❤×血量 + 金币身价 + `钓到 N 次 · 最高 X` + 一句话简介 + 所在海域 |
| **未钓获** | **全黑剪影** + `？？？` + `未 钓 获` + 只透露"这一层海域里还有一条没见过的鱼，把鱼线放到 −XXm 以下试试" |

**为什么未知鱼是全黑的**：图鉴图标不是 3D 缩略图，而是 **canvas 2D 现画**的侧视鱼，
和 3D 模型**共用同一套特征参数**（嘴型 / 鱼鳍 / 尖刺 / 条纹 / 扇鳍 / 触须…）。
好处是"未解锁"只需要换一套调色板 —— 所有颜色映射到同一个近黑色，
轮廓照旧准确，既保留了辨识度又不剧透。未解锁的剪影另外描一层冷蓝色细边，免得糊成一团。

**金币 / 血量心形 / 「⚠ 扣钱」徽章全是内联 SVG**（`src/icons.js`），不是 emoji —— 原因见下面「技术要点 · 图标」。

## 部署到 GitHub Pages

项目是纯静态站点，无需任何构建步骤。

### 方式 A：部署到仓库根路径（推荐）

```bash
git init
git add .
```

2. **Source** 选择 `Deploy from a branch`
3. **Branch** 选 `main`，目录选 `/ (root)`，点 **Save**
4. 等 1~2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

### 方式 B：部署到子目录

把 `index.html`、`styles.css`、`src/`、`vendor/` 全部复制进一个新建的子目录（例如 `site/`），
Pages 的目录改选 `/<那个目录>` 即可。

> ⚠️ **不要用 `docs/`** —— 那个目录已经被数值参考文档占用了（见 [`docs/README.md`](./docs/README.md)）。

### 方式 C：GitHub Actions（自动化）

`.github/workflows/pages.yml`：

```yaml
name: Deploy to GitHub Pages
on:
  push: { branches: [main] }
  workflow_dispatch:
permissions:
  contents: read
  pages: write
  id-token: write
concurrency:
  group: pages
  cancel-in-progress: true
jobs:
  deploy:
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - uses: actions/checkout@v4
      - uses: actions/configure-pages@v5
      - uses: actions/upload-pages-artifact@v3
        with: { path: . }
      - id: deployment
        uses: actions/deploy-pages@v4
```

> 仓库里已包含 `.nojekyll`，避免 Jekyll 处理静态资源。
> 所有资源路径都是**相对路径**，因此放在仓库根目录或任意子目录都能正常工作。

## 技术要点

**竖屏适配**
画布在手机上全屏，宽屏时自动收敛为 9:16 竖屏栏并居中。
正交相机的视口保证**最小可见宽度 154 世界单位**，所以玩法尺度在任何屏幕比例下完全一致 ——
超长屏（20:9）会多看到一些纵向深度，但左右活动范围不变。

**图标为什么用内联 SVG 而不是 emoji**（`src/icons.js`）
界面上所有图标都是内联 SVG，**整个界面里一个 emoji 都没有**
（`verify6` 的 `C11` 断言会全量扫描页面可见文本把这条钉死）。一共 **30 个**：

- **HUD / 通用**：金币 · 手机 · 信号 · Wi-Fi · 电量 · 返回 · 音效 · 静音 · 警告 · 血量 · 垃圾桶 · 信息
- **手机 App**：渔具店 · 图鉴 · 设置 · 航线
- **升级项**：鱼线 · 鱼钩 · 铅坠 · 灯具 · 鱼护 · 鱼饵 · 绞盘 · 快速回收（工具按钮）
- **场景 / 动作**：抛竿 · 海面 · 浮冰
起因是**金币图标在宿主界面里显示不出来**，排查后发现 emoji 有三个硬伤：

1. **字形来自系统 emoji 字体兜底，而游戏的字体栈一个 emoji 字体都没声明** ——
   靠兜底补上的字形，换个渲染环境就可能变空白。
2. **彩色 emoji 是位图字形，不受 CSS `color` 控制** —— 界面里图标需要跟着文案变色，emoji 做不到。
3. **13px 字号下 🪙 的占位是 17.9×19px**，而 HUD chip 的行高正好 19px ——
   emoji 基线偏低会**把整行文字顶下去**，chip 高度被撑变形。

换成 SVG 之后：矢量随字号缩放、颜色由 `currentColor` 控制、不依赖任何宿主字体。

> **避坑 1：不要用 `<defs>` + `linearGradient`。** 这些图标会注入到页面多处，
> 每处都带一份同名 `id` 的渐变定义会互相冲突（浏览器取第一个匹配到的 `id`），
> 第二处之后的图标全变成第一处的颜色。改用**纯色层叠**（深色底 + 亮色面 + 高光弧）模拟金属感。

> **避坑 2：N 芒星需要 2N 个顶点**（N 个外尖 + N 个内凹）。
> 只给 8 个顶点画出来的不是八芒星，而是「四芒星 + 四个凹口」，看着像 ✦ 而不是爆炸。
> `icons.js` 里的八芒爆炸星是按 22.5° 步长生成 16 个顶点算出来的。

> **图标观感没有任何断言测得到**，改完 `icons.js` 请跑 `node .dev/shots-icons.mjs`，
> 它会把整套图标按 64px（看形状）和 19px（看真实尺寸下的可读性）铺成一张总览图。

**正交缩放**
空中阶段需要「镜头拉远看全局」，所以 `World` 把相机拆成 `baseView`（由屏幕比例算出）
和 `viewScale`（每帧可变的拉远倍率）。改 `viewScale` 只重算 `left/right/top/bottom`，
`screenToWorld` / 视野剔除 / 爆炸特效缩放全部跟着走 —— 点击坐标在任何缩放级别下都准确。

**3D 表现**
所有鱼、船、渔夫、水面、云、星空、月亮、光晕、深海地形都是**程序化生成**的几何体，没有外部模型文件。

- **卡通阶梯着色**：`MeshToonMaterial` + 一张 3 段阶梯贴图（steps `[86, 168, 240]`）。
  之前鱼身用 Lambert，在正交视角下会糊成一片色块；换成阶梯着色后明暗有明确分界，体积感立刻出来。
- **旋转体鱼身**：`LatheGeometry` 按剖面旋转出流线型身体（替代压扁球体），
  再配一层 BackSide 反面外壳描边，让正交视角下的鱼"立"起来。
- **深海地形**：固定种子 PRNG（`seed = 20260914`）生成岩石 / 海带 / 神秘光球与遗迹，
  每次刷新地图完全一致，方便调试与录屏。
- 鱼做 ±30° 的偏航摆动，正对相机也能读出立体体积。
- **船随浪摇晃**：起伏 + 左右摇摆（约 6.6°）+ 轻微俯仰，由三条不同周期的正弦叠加而成；
  竿梢每帧从鱼竿的世界矩阵重算（`rod.localToWorld`）—— 船一摇，鱼线起点和抛竿起抛点都跟着走，
  不会出现"船动了鱼线还挂在原地"的脱节。
- **夸张造型**：38 种鱼共用一套"特征参数"驱动（`belly` 大肚皮 / `spots` 斑点 / `stripeN` 条纹 /
  `fangs` 獠牙 / `whisker` 触须 / `bignose` 大鼻 / `fanTail` 扇尾 / `fanFin` 扇鳍 / `crestColor` 冠色），
  所以鮟鱇有大獠牙和发光钓竿、狮子鱼有三片大扇鳍、皇带鱼是细长银带、河豚是鼓起来带尖刺的球。
  参数不同造型就不同，但代码路径只有一条。

**扣钱鱼的"一眼可辨"三层信号**（这是本轮重点：玩家必须在不看说明的情况下躲开它们）
1. **暗红描边** —— 普通鱼是深蓝描边 `#0a1524`，扣钱鱼换成暗红 `#8c0f14`，深海里也能看出"这条不对劲"
2. **脉冲红晕** —— 一层加色混合的红色椭圆光晕，透明度在 `0.26 ~ 0.50` 之间以 `5.2 rad/s` 脉动，
   同时整体尺寸在 `0.93 ~ 1.07` 之间轻微呼吸。光晕按体型拉成椭圆：细长的电鳗是一条长红晕，河豚是一个圆红晕
3. **⚠ 徽章** —— 挂在鱼头顶，正对镜头。实现方式是给它一个**反向自转的枢轴**，
   每帧把 `pivot.rotation.y` 设成父级偏航的相反数，于是无论鱼怎么摆尾、相机怎么拉远，徽章永远正对观众

> 徽章尺寸基准踩过坑：一开始按"最长边"（`L`）缩放，结果细长的电鳗（`L = 9.0`）被 8.55 宽的徽章整条盖住。
> 正确的基准是**视觉厚度**（`H`）：`bs = max(H × 1.15, 2.2)`。装饰件的尺寸要跟着"看起来有多粗"走，不是"有多长"。

**性能**
- 同一鱼种共享几何体与材质
- 零碎部件（鳍 / 尖刺 / 触手 / 王冠 / 条纹 / 斑点 / 獠牙 / 扇鳍）在构建期**合并成单个 BufferGeometry**
  （斑点用斐波那契球分布撒扁球，只保留 `|z| > 0.42` 的两侧，最后并成 1 个 draw call）
- 眼睛用一张贴图平面代替「眼白 + 瞳孔」两个 mesh
- 挂上鱼线的鱼自动切换为**简化模型**（只保留身体 + 尾巴），鱼线上最多同时渲染 30 条
- 按相机深度范围剔除场景外的鱼
- 云 / 神光 / 海雪在离开对应高度后直接 `visible = false`，不浪费 draw call

结果：最深处的极端情况也只有约 **300 draw call / 11k 三角形**（优化前是 790 / 43k）。

**音效**
全部由 WebAudio 实时合成（振荡器 + 噪声 + 滤波器），没有音频文件。
浏览器自动播放策略要求用户手势后才能出声，所以首次点击会解锁 AudioContext。

**存档**
金币 / 升级等级 / 枪械（拥有 / 当前 / 各自等级） / **直达深度偏好**（开关 + 目标深度） /
最深纪录 / 最高飞行纪录 / **图鉴记录** / **音效开关** 存在 `localStorage`，
键名 `hooked.save.v3`。
图鉴字段是 `save.codex = { [鱼id]: { n: 钓到次数, best: 最高身价 } }`。
清空存档的入口在**手机 → 设置**里（带二次确认），不再放在标题页。

> ⚠ **老存档不用换 key**：存档里存的是**等级**（Lv0~Lv20）而不是数值本身。
> v0.5 删掉了 4 项升级（攻击力 / 保险 / 声呐 / 加固），老档里那 4 个键读档时会被直接忽略，
> 剩下的等级含义不变 —— 不会读出 `undefined` 把物理打成 NaN。

> **验证周期性动画（比如船的摇晃）时，采样窗口至少要覆盖一个完整周期。**
> 船的摇摆慢波周期约 11.6s，用 1.8s 的窗口去采，测到的是"斜率"而不是"幅度"，
> 会得到"船几乎没动"的错误结论。

无头 SwiftShader 帧率只有 ~30fps 且抖动很大，靠 `requestAnimationFrame` 跑不完
黄金鱼王 20 秒的飞行，所以脚本会先把渲染循环冻住，再用固定 `dt = 1/60` 手动推进 `_update`。
这样模拟结果完全确定，跟真实设备的结论一致。

> **但冻住 rAF 会连带冻住 CSS 过渡**：headless 里没有帧就不会推进过渡，
> `getComputedStyle` 读到的会是过渡的**起始值**（比如隐藏元素的 `opacity` 读成 `0.919` 而不是 `0`）。
> 所以凡是验证 CSS 动画/过渡的断言，脚本必须自己用 `requestAnimationFrame` 撑帧，
> 再用 `waitFor()` 轮询到目标状态，不能用固定 `sleep`。

> **宽屏出图要三件事一起做**：`Emulation.setDeviceMetricsOverride` 设尺寸、
> 显式调一次 `world.resize()`、并且解除 `#stage` 的 9:16 锁
> （`style.cssText += ';width:100vw!important;height:100vh!important'`）。
> 只做第一步的话，截图还是 430×932 的手机画布，HUD 会糊在上面。

> **改尺子总量这类"分母"时要检查依赖它的阈值。** 迭代 6 把深度尺总量从 470m 换成
> 地图上限 860m，Lv4 的 840m 极限线落在 97.7%（v0.2 世界 ×2 后仍是同一个比例），顺带暴露出 `setLineLimit()`
> 原本按**绝对值**判断"贴底"（`maxDepth >= total - 20`）的 bug ——
> 改成按百分比 `pct >= 0.985` 之后，换地图、换上限都不会再误隐藏。
> **教训：凡是"贴边/贴底"这类判断，用百分比比用绝对值稳。**
