# 荒唐钓鱼 · 深海重制版（2D）

> **概述**：把旧版竖屏钓鱼 demo 重制为 **Canvas 2D 矢量插画风**、单文件离线可跑的版本。保留「下潜躲鱼 → 收线撞鱼 → 抛射出水面 → 空中点射」核心循环与竖屏布局，只重做渲染层——物理、经济、剧情、存档一行未改。
> **状态**：可运行。`npm run typecheck` 与 `npm run build` 通过，产物为单文件 `dist/index.html`（约 370 KB / gzip 121 KB），零外部请求、零素材文件。
> **读者**：想改代码或验收的人。为什么放弃 3D、画面是怎么搭的，看 `../docs/07-2D重制说明.md`。
> **关联**：`../docs/01-原demo结构梳理.md` ~ `../docs/05-交付说明与自测报告.md`（3D 版时期），`../docs/07-2D重制说明.md`（当前版本）。

### 一局的完整流程

```
标题页 → 序章（漫画 6 格 → 翠花来电 → 镇长公告）→ 岸边（idle）
      → 点击屏幕 → 抛竿（甩杆 1.2s，钩子飞出入水）→ 下潜
      → 咬钩 / 到底 → 收线 → 出水面 → 空中射击 → 结算
```

序章只播一次（`fired` 去重）；之后每次回岸边都直接是 idle。

**剧情投放的节奏**（2026-10 调整）：

| 时机 | 内容 |
| --- | --- |
| 点「开始游戏」 | 只有序章漫画（6 格），约 60 秒后就能下钩 |
| 第 1 局结算后 | 翠花来电（升级鱼线 / 别打水母）+ 镇长公告 |
| 60m / 120m / 200m | 未知号码、爷爷的线索、凯文漫画 |
| 180m + 图鉴 8 种 | 「北方还有一片海」——航线里出现冰海的线索 |
| 250m + 图鉴 11 种 | 爷爷来电，船票信息 |
| 冰海 300m / 鱼王 | 收尾 |

### 岸边目标条

idle 状态下，底部会显示一条「🎯 下一步」：下潜到多少米、攒多少钱、还差几张图鉴，带进度和手机入口。
目标按**当前状态**判断（不是按事件），所以跳级也不会卡住。

下面还有一条更淡的**支线目标**，直接从成就表里挑离得最近的一条（8 条鱼 → 20 条 → 8 连 → $1200 → 瓶子 → 18 种 → 4 把枪 → 鱼王）。主线管「去哪」，支线管「这局顺手还能干什么」。

### 手机：分阶段解锁 + 红点规则

短信、电话、鱼博、剧情是**四个独立 App**，不再挤在一个界面里：

| App | 内容 | 解锁条件 |
| --- | --- | --- |
| 💬 短信 | 会话列表与对话 | 始终 |
| 📞 电话 | 通话记录（未接红字） | 始终 |
| 🐦 鱼博 | 帖子流 + 渔市快讯 | 第 1 次出海 |
| 🎬 剧情 | 漫画 + 漂流瓶 | 始终 |
| 📖 鱼鉴 / ⚙️ 设置 | — | 始终 |
| 🎣 渔具 | — | 第 1 次出海 |
| 🔫 枪铺 / 🏆 档案 | — | 第 2 次出海 |
| 🧭 航线 | — | 40m 或 3 次出海 |
| 🎩 帽子 | — | 第 4 次出海 |

红点不再是一个混在一起的总数：

- **红色数字** = 主线未读（未知号码、爷爷、冰海 NPC、关键剧情短信、漏接电话）
- **青色小点** = 只有普通未读（鱼博烂梗、支线）
- **进入 App 即清零**该 App 的 `unread` 与 `unreadKey`，与从哪进（图标 / 灵动岛 / 结算页）无关
- 新解锁的 App 左上角有 `NEW`，进一次后消失
- 漫画播完立即清零（不会出现「看过的序章还挂红点」）

### 主界面

- 顶部正中是**地图名（27px）+ 一行天气**（「☀️ 晴 · 风平浪静」），左上角不再重复地图名
- 岸边底部没有「下钩」按钮，只有一行半透明的「点击屏幕任意处下钩」提示
- 左下角是**纯图标**的手机按钮：无边框无文字，有未读时叠红色数字（普通未读是青色小点）
- 出海后手机通知（灵动岛）自动隐藏，回岸再出现
- 底部两组 UI（岸边/钓鱼）用「朝屏幕边缘滑出 + 淡出」的缓动切换，回岸时反向播放

### 天气

天气同时影响画面和鱼群。回岸时 58% 概率变天；**下潜途中每 55 米还会再掷一次骰子**
（40% 概率换），换天会立刻改画面和之后的刷鱼权重，并弹一句「变天了」：

| 地图 | 天气 | 画面 | 鱼群 |
| --- | --- | --- | --- |
| 阳光湾 | ☀️ 晴 | 暖调、通透 | 巡游 +10% |
| 阳光湾 | ⛅ 多云 | 光稍弱 | 巡游/冲刺 + |
| 阳光湾 | 🌧️ 小雨 | 冷调、雨丝 | 群游 ×1.95，伏击 ×0.78 |
| 阳光湾 | 🌫️ 海雾 | 灰白雾幕 | 伏击 ×1.7、稀有 ×2.3 |
| 极光冰海 | 🌌 极光 | 绿色调、光尘上浮 | 稀有 ×2.4 |
| 极光冰海 | 🌨️ 暴雪 | 雪点、雾浓 | 群游 ×1.5、稀有 ×0.75 |

数值在 `src/game/data.ts` 的 `WEATHERS` 里，`bias` 的倍率直接改就行；画面参数是 `fog / light / tint / particle`。
局内变天的规则在 `engine.ts` 的 `updateDescent()` 开头（步长 55m、概率 0.4）。

### 命中反馈

- **命中定格（hitStop）**：中弹瞬间把世界 `dt × 0.05`，持续 `0.035 + 0.075 × min(1, hp/8)` 秒。
  只压时间不暂停渲染，血越厚停得越久；取 max 不覆盖，连发枪不会把前一枪的定格缩短
- **溅汁**：中一枪喷出 `sp.color / color2` 的液滴（普通混合，不是加色），
  带重力、按速度拉长、跟着被顶飞的鱼一起走；命中点还有一团极短命的色斑
- 鱼被打中后**保持原尺寸**，只做挤压回弹（以前会因为把「倍率」当「米数」而缩小）
- 没打死的鱼会被顶高：第一枪 +18，第二枪 +24（叠在上一次未落的速度上）。
  顶飞有 **0.22 秒冷却**，否则加特林一秒 20 发会把同一条鱼顶出大气层
- 转速**沿当前方向叠加**（不重新随机），否则每一枪都像被按了反向键
- 飘字是「还差 N 枪」（`ceil(hp / dmg)`），比报剩余血量直观
- 第二枪的冲击环、火星、震屏（最多 +1.1/枪）全部更大
- **打死的鱼当场消失**，只留碎光和 `+$`，不再有 0.8 秒的缩小淡出
- HUD 上的金额 = 已入账 + 钩上 + 空中（`gross + estimate + airValue`），打死一条不会让数字往回掉

### 水面衔接

`above`（水上权重）由镜头高度连续换算 `clamp(0.5 + camY / 4, 0, 1)`，不再按阶段给 0/1。
背景层把天空只画在水线以上那一条（`clip` 到 `screenY(0)`），透明度跟着 `above` 走，
所以下潜是「水线往屏幕上方滑、天空慢慢透成水色」，上浮是它的逆过程——水下抬头还能看见头顶那层水面。

镜头：入水时用 `camOffset(depth) = 1.2 + min(1, depth/6) × 3.4` 跟着钩子同步下沉；
出水前 2 米天空就已经恢复。收线时相机 `k = 12` 并带 **lead 补偿** `-vy/k`，
所以钩子不会越跑越贴屏幕底。

### 水下 → 收线的三段式

不再「急刹 → 原地静止 → 猛地反向」，而是照着惯性来：

| 段 | 曲线 | 效果 |
| --- | --- | --- |
| 刹停 | `y = y0 − D(2u − u²)`，`D = v0·T/2`，T=0.5s | 起手速度正好等于刹车前的下潜速度，带着惯性滑出去再停 |
| 起拉 | `y = y0 + D(3u³ − 2u²)`，`D = 收线速度·T/5`，T=0.6s | 起手速度 0，中间先微微一沉（anticipation），末端正好接满速 |

### 空中阶段

- 滞空 **4 秒左右**（重力 `AIR_G = 12`），鱼按身价飞：`v0 = 23 + √value × 0.55`，贵鱼更高更难打
- 按捕获顺序**扇形铺开**，先定「该飘多远」再反推水平速度，贵鱼不会飘出画面
- 相机**跟最低的那条**（最快落水的，最该先打），推近到 `zoom 0.72`，横向跟着走。
  但**跳过扣钱的鱼**：水母这类 `value < 0` 的，钓上来甩上天是失误，镜头不该凑过去；
  天上只剩它们时，镜头回到水面附近
- 高空有 8 层云带（11 / 19 / 31 / 47 / 70 / 98 / 132 / 175m），飞上去能看出高度
- **天空目标**：海鸟（hp2 / $60）、飞机（hp6 / $260）、UFO（hp12 / $800），
  最多同时 3 个、1.8~4.2 秒刷一个，打下来纯加分、**不拦结算**
- 结算页在「毛收入」下面单独列一行「└ 击落 海鸟 ×2」+ 金额（它已经算在毛收入里，不会重复加）
- 出水瞬间有 0.22 秒慢动作（世界 0.32 倍速）+ **整屏白水幕**（下半屏渐隐，约 0.45 秒散完）

### 抛竿

二阶物理：出手给初速 `7 m/s`（向上）+ 重力 `16`，滞空约 1.15 秒。
水平方向每帧按「剩余滞空时间」反算需要多少速度（`(want − x) / remain`），再做一次短平滑 ——
所以**岸边点哪儿、钩子就甩到哪儿**（实测落点误差 ≤ 0.05m），同时保留一点惯性。
入水后 0.3 秒接 `descent`，另有 2.8 秒保险丝防止卡在 cast。

### 灵动岛通知

强剧情不再全屏打断，改成顶部一个常驻卡片：

| 类型 | 表现 | 时长 |
| --- | --- | --- |
| 强制来电 | **只剩「接听」**，HUD 全部隐藏、全屏压暗、点哪里都只能接 | 不接不走 |
| 普通来电 | 头像 + 名字 + 拒绝/接听 | 常驻（拒绝后 5 秒再弹） |
| 公告 | 横幅，8 秒后收成小胶囊 | 22 秒后自动让位 |
| 系统通知 | 📲 新应用解锁 | 同公告，但优先于普通公告 |
| 短信 | 头像 + 内容预览 + 消失进度线 | 4.5 秒自动消失，最多 5 条排队 |

优先级 **强制来电 > 来电 > 短信 > 系统通知 > 公告**。全屏只留给漫画和漂流瓶。

**强制来电**只有四通主线电话：120m 的「海底的瓶子」、180m 的「北方还有一片海」、250m 的「爷爷还活着」、冰海 300m 的「鱼王与假牙」。这四通电话期间：

- HUD（钱/地图/枪/线/深度/目标条/手机）整块不渲染
- 幕布压暗，只剩屏幕上方的来电卡片和红色呼吸光
- 没有拒绝键、不能上滑、不能按 Esc、点屏幕不会下钩
- 接听 → 直接进通话；结束后 HUD 自动回来
- **不做超时未接**：切后台、刷新、关掉重开，回来仍然是这通电话在等你（接听时不从队列移除，通话结束才清）

点岛上的卡片会直接进对应界面，不会再误触「开始钓鱼」：

| 点哪里 | 去哪里 |
| --- | --- |
| 短信 | 手机 → 短信（对应会话列表） |
| 公告 | 手机 → 通知栏，并展开这一条 |
| 来电 | 展开 / 接听 |

岛展开时顶部 HUD 会自动淡出下移让位，收起后恢复。上滑（>26px）可以收起：短信=丢掉，来电=稍后再打，公告=收成胶囊。

### 手机通知栏

状态栏右上角的 🔔 就是通知栏：

- **公告 / 系统通知**：点一下展开全文（岛上的卡片 22 秒后会消失，这里永久留档）
- **未接来电**：红字，点一下进对应短信会话
- **新消息**：点一下进对应会话

`SaveState.notices` 存公告与系统通知，老存档默认空数组，不需要迁移。

### 通话记录

手机 → 短信 → 消息页顶部有「📞 通话记录」：接过/漏接都记一笔，漏接是红字；之后再接听会自动升级成已接。

抛竿是**真实过渡**而不是切场景：镜头从船上看着人物甩杆，钩子入水后镜头跟着沉下去。`above`（0~1）连续插值控制天空/水体的配色、光柱强度与入水白闪，所以不会出现「啪」一下换场景。

## 四、调试钩子

URL 带 `#debug` 时，`window.__af` 指向引擎实例：

```js
__af.debugState()              // 阶段、鱼钩坐标、空中目标、击杀与射击次数
__af.stage.worldToScreen(x,y)  // 世界坐标 → 屏幕坐标（自动化测试点鱼用）
__af.stage.cam                 // 当前相机：cy / scale / shake
```

HUD 根节点带 `data-phase`（`idle|cast|descent|turn|ascent|shoot`），方便脚本判断阶段。

## 五、画质分级

2D 下画质只影响**分辨率与装饰层**，不影响玩法、构图与判定：

| 档位 | DPR 上限 | 焦散光斑 | 远景鱼影 | 颗粒 | 近景剪影 |
| --- | --- | --- | --- | --- | --- |
| 流畅 low | 1 | 关 | 关 | 关 | 开 |
| 均衡 mid | ≤1.5 | 关 | 开 | 开 | 开 |
| 精美 high | ≤2 | 开 | 开 | 开 | 开 |

默认 `high`，可在标题页、暂停面板、手机设置里切换，立即生效并写入存档。
