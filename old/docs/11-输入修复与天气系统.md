## 1. 不能开枪、钩子不动（P0）

**根因**：手机上把 HUD 包进了一层 `.hud-shell`（为了开手机时整块淡出），
它是 `position:absolute; inset:0` 的全屏 div，但没有 `pointer-events: none`。
结果 canvas 永远收不到 `pointerdown`——钩子拖不动，空中点鱼也不开枪，
而 `smoke` 当时只断言相位，没断言 `shots`，所以一直是「假绿」。

**修法**：`.hud-shell { pointer-events: none; }`，按钮各自带 `.pe` 重新打开命中。

实测（`play.mjs`）：钩子 `targetX 0 → -2.09`，连点 4 次 `shots=4`、`kills=2`、`gross=34`。

## 3. 抛竿：去掉「弹动」

三个原因叠在一起：

1. 鱼钩初始写死在 `(2.6, 2.5)`，而杆尖在 `(3.25, 2.76)`——第一帧会「啪」地跳过去；
2. 滞空时每帧按「到落点距离 ÷ 剩余时间」重算水平速度，目标近时会来回找；
3. 出手速度的符号写反，钩子其实是被「往下扔」的。

改法：

- 起点直接取 `world.rodTip()`；
- 出手时一次算好 `T = clamp(0.62 + |dist|*0.09, 0.62, 1.05)`、`vy = (h - gT²/2)/T`、`vx = dist/T`，
  之后只做纯抛体积分，**不再中途修正**；
- 出手时机从 `t=0.4` 提前到 `t=0.26`（杆尖最高、刚开始前送）——0.32 时杆尖已经在往下扎，钩子会先向下再向上。

`cast.mjs` 采样 26 帧：`vx=const`、变号 0 次，轨迹 y 由 2.6 → 4.1 → 落水，一条干净的弧。

**补修（用户反馈「还是会弹、出钩位置不对」）**：`drawRod` 里杆尖的屏幕 y 写成了 `py + cos(a)*L*s`，
而钩子/钓线用的是世界坐标 `rodTip() = pivot.y + cos(a)*L`（屏幕 y 向下为正，必须取负）。
两者差了 `2*cos*L ≈ 3m`——画出来的杆一直扎在水里，钩子却从半空中的「隐形杆尖」飞出去。
改成 `py - cos(a)*L*s` 后，杆指向右上方，钩子、钓线、杆尖三点重合。
`track.mjs` 逐帧记录屏幕坐标：世界 y 轨迹是 3.0 → 4.1 → 下沉，只有一次自然抛物线转折。

## 4. 渔夫坐姿

原来是一个直立的火柴人站在甲板上。现在：

- 甲板上放一只木箱凳（有顶板、木纹、底部阴影）；
- 髋部落在箱面（局部 -0.34s），膝盖前伸、小腿垂下、雨靴踩甲板；
- 左臂搭在膝盖上，右臂前伸握住杆柄（杆的支点 `ROD_PIVOT(0.78, 1.24)` 不变，所以抛竿逻辑不受影响）；
- 远侧腿压暗做出前后层次，大腿上沿补一道逆光。

- 海雾：贴着水面的 5 条横向雾带，缓慢漂移；
- 雷雨：每 5.2 秒一次双段爆闪 + 一道锯齿闪电（`hash` 生成分叉，不用贴图）；
- 雨：更密的斜雨 + 水线上的涟漪；暴雪：带横风的雪；
- 浪高同时作用于船身起伏、浪花和斯涅尔窗的水纹振幅。

## 8. 左下角手机：真机形象 + 来电震动（2026-10-22 下午）

原来是一个 24px 的 📱 emoji，40×40 的按钮。现在抽成 `PhoneFab` 组件（`ui/common.tsx`），
主屏左下角和标题页右上角共用：

- 按钮 52×66，机身 44×60：金属渐变边框、圆角屏、顶部摄像头凹槽、2×2 彩色 App 图标、底部 home 条；
- 未读角标贴到机身边角（`.phone-fab .dot-num { top:1px; right:1px }`）；
- 有来电且岛上的来电卡片处于「展开等接听」时，按钮加 `.ringing`：
  - `.pf-body` 跑 `phoneBuzz`（0.46s 循环，±9° 摇晃 + 1.5px 平移）；
  - `::after` 加一层红色呼吸圈（`ringHalo`，1.1s，透明度 0.85→0.2 循环），不会完全消失；
  - `prefers-reduced-motion` 时两个动画都关掉。
- **震动时点手机 = 直接接听**：`onPhone` 先看 `callToAnswer`，有就 `openStory(uid)`（进通话），没有才打开手机界面。
  想单纯看手机，先在岛上点「拒绝」把来电收成胶囊，震动停止后点手机即可。

**为什么不是「有 call 就震」**：岛上的来电被拒绝后会收成胶囊，但队列项还在；
    直接用 `island.some(kind==='call')` 会一直震。现在用岛回传的 `onExpanded` 状态判断，
    收起就停、5 秒后重试展开又震。

## 9. 高空镜头与太空（2026-10-22 下午）

### 9.1 镜头追不上鱼

三个原因：

1. `updateCamera` 的射击分支把目标 `clamp(..., -1, 40)`——鱼超过 40m 镜头就不跟了；
2. 跟随速度 `k=4.2` 偏慢，鱼被顶飞时稳态误差 = v/k 太大；
3. 只跟「最低的那条」，玩家正在连击、被顶高的那条会被镜头丢掉。

改法：

- 上限 40 → **620m**，`k` 4.2 → **7**；
- `AirFish` 加 `focusT`：每次非致命命中重置为 1.5s，镜头优先跟 `focusT > 0` 的鱼，
  玩家连点就能把同一条鱼一路送出大气层；没有焦点时仍回到「最低优先」；
- 视野随高度拉开：`zoom = 0.72 → 1.57`（25m 起算，115m 到顶），越高看得越宽。

`focus2.mjs` 实测（同一目标连打 6 次）：鱼 y `5.3 → 25.7`，镜头 `4.6 → 24.2`，滞后约 1.5m；
`space.mjs` 把鱼放到 70/180/320m：镜头 `66.2 / 175.8 / 314.0`，鱼始终在屏幕 y≈440–450。

### 9.2 空中重力

`AIR_G` 12 → **9.2**：初速不变时最高点提高约 30%，滞空更久；`AIR_TIMEOUT` 14s → 18s。

### 9.3 天空内容

`background.ts` 新增 `spaceSky()`，按高度分三段：

| 高度 | 画面 |
|---|---|
| < 70m | 原样（蓝天 + 太阳 + 高云） |
| 70–120m | 压暗成深空、星星淡入、偶尔一颗流星 |
| > 120m | 地球弧线从屏幕下方升起（大气辉光 + 云带），> 190m 左上角出现月亮 |

高度是从水线位置反推的 `alt = (toScreenY(0) - H/2) / scale`，所以镜头一动空间层就跟着动。
另外高空时雨雪、低云、天气色罩都会自动退出（`alt > 60/110/150`），太空里不会下雨。
