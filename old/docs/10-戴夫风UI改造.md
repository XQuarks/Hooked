## 2. 组件规律（六条）

1. **面板** = 深青黑底 + 1.5px 霓虹青描边 + 中青标题条
2. **列表行** = 方框图标 + 名称 + 数值 + 右侧计数；行间细线，选中行填 `#2c7494`
3. **按钮只有两档**：品红（主）/ 深灰带键位帽（次），圆角 4~6px，**不是胶囊**
4. **三种浅底**：剪贴板纸 / 羊皮纸 / 米黄，浅底一律深色字
5. **弹窗** = 彩色标题带 + 霓虹青发光描边 + 大号斜体标题
6. **BEST 蓝标**贴在「这是历史最好」的数值旁

## 6. 第二轮：逐 App 还原（同日晚）

第一轮只换了色板，布局还是原来的深色卡 —— 看起来"像戴夫风"但不像截图。这一轮**按 App 逐个对照参考图重做**，核心判断是：

> **戴夫手机里的 App 是浅色的**（白 / 米黄 / 浅蓝），不是统一的深海蓝。
> 深青黑只属于 HUD 和游戏内面板；手机里每个 App 有自己的主题色。

### 6.1 主题系统

`Phone.tsx` 在内容外包子一层：

```tsx
<div className={`app-shell app-${app}${LIGHT_APPS.has(app) ? ' lt' : ''}`}>{content}</div>
```

- `.app-sms` / `.app-calls` / … 各自定义 `--app-bg` 与 `--app-head`（标题条渐变）
- `.lt` 是浅色主题：白卡、深字、浅分隔线、品红/绿标签

这样 11 个 App 共用一套组件，只换变量，不用改每个 App 的 JSX。

## 7. 五项体验修正（2026-10-22）

用户贴了 5 张实机截图逐条指出问题，全部修完。

### 7.1 结算页文字看不清

**根因**：`.result-msgs .rm-row span` 还留着第一版的浅蓝 `rgba(210,232,244,.78)`，
在米黄便签上几乎隐形。

改成深褐 `#3a3020`（与便签同色系），副标题 `.result-total .cap` 从 `#6b7680` 再压深到 `#4d5862`。

补记（第二轮复核）：便签右下角的「点开看全部 ›」原来是 `rgba(160,200,220,.5)`（浅蓝，在米黄上几乎看不见），
压成 `#8a7440`；结算结语那行原来是 `var(--dim)`（#8fb2c4），改成 `#6f6656`。

### 7.2 短信右侧数字应随会话已读

用户红框圈的是**标题栏右上角那个红底角标**（`.app-shell.lt .tag`，粉底+粉边，就是截图里的「红框」）。
原来它写的是「这个会话一共几条消息」，永远不清零。

改成真正的未读，行内和标题栏两处一起走：

- `SaveState.seen: Record<会话 id, 已读条数>`（老存档由 `{...defaultSave, ...parsed}` 自动补空对象）
- **行内**显示 `总条数 − seen[id]`，为 0 时不渲染
- **标题栏**显示 `${未读合计} 未读`；全部读完变成 `已读`，并用 `.tag.read` 褪成中性灰（不再用红框提醒）
- 点开会话立即写入 `seen[id] = 总条数`

实测：进短信时「3 未读 + 老妈 2 / 大炮哥 1」→ 读完老妈「1 未读 + 大炮哥 1」→ 全读完「已读 + 无角标」。

### 7.3 去掉暂停面板的画质

暂停面板里那组「流畅/均衡/精美」删掉了（画质只在手机「设置」里调）。
⚠ 第一次改时用 Edit 把画质块**插到了自己前面**，变成两份；发现后整段删除并留了一行注释。
⚠ 验证脚本原来点的是「暂停」按钮，但那个按钮只在「钓鱼中」才渲染，岸边根本点不到，
导致 `hasQuality` 是「面板没打开」的假通过。改成按 `Esc` 打开，并断言 `opened === true`。

### 7.4 鱼鉴详情：鱼太大、文字看不清

两个问题叠在一起：

1. **文字**：描述是 inline `color: '#cfe8f5'`（浅蓝），在米色纸上读不出来 →
   改成 `.dex-desc`（米黄卡片 + `#3d4550` 深字）。
2. **鱼图**：原来用 `FishViewer`（canvas + 自绘径向背景），在纸面弹窗里会画出一大块
   带几何边缘的浅色块，鱼只是一条细线。改成图鉴网格用的 `Thumb`（矢量缩略图），
   hero 背景换成中深蓝 `#4b82ab → #2f5f86`，浅色鱼（沙丁鱼）和深色鱼都能看清。
   `Thumb` 新增 `maxW` 参数（默认 120，详情页用 260）。

### 7.5 手机应该从下方升起、不占满屏、背景可见

| 项 | 之前 | 现在 |
|---|---|---|
| 容器对齐 | 居中 | `align-items: flex-end` 贴底 |
| 高度 | 100% | **84%**（顶部露出约 144px 场景）→ 下午按新红框改为 76%/72%，见 §8 |
| 圆角 | 四角 28px | 只圆上两角（像抽屉） |

## 8. 截图微调：手机宽度 / 金币底框 / 标题位置（2026-10-22 下午）

用户又贴了三张带红框的截图。红框位置用像素扫描量出来，不靠目测：

| 项 | 红框实测 | 改完 |
|---|---|---|
| 手机浮层 | 宽 72%（x 16%→88%），顶边 24.4%，底边贴屏幕 | **宽 72%、高 76%**、`top 216/900 = 24%`、`left 60` |
| 金币底框 | 参照右侧「爷爷的老手枪」chip | 去掉斜切与金边：`--glass` + 1px `--line` + 5px 圆角，金币和数字仍为金色 |
| 标题 | 目标框约 316×197，上沿 29.5% 高 | 3 字 96px（实测宽 305）、4 字 75px（318），`top 270/900 = 30%` |

标题字号是按字数算的（`300 / 字数`，夹在 44–96px），所以「阳光湾」和「极光冰海」的视觉宽度都在 300–320px，不会四字爆框。

### 连带修的三处

1. **标题挪出 `.hud-top`**：原来它和金币/chip 同层，通知展开时 `.hud-top.dim` 会整块 `opacity: 0`，把移下来的大标题也带没了。现在标题是 `.hud-layer` 的直接子元素，通知展开照常显示。
2. **`hud-map` 的隐藏时机**：从「只在射击阶段隐藏」改成「只要不是在岸边就隐藏」——96px 的字压在水下画面上没法看。
3. **手机 4 列图标被顶出屏幕**：`.app-icon` 是 `<button>`，浏览器默认 `padding: 1px 6px` 让每列最小宽度变成 72px；手机缩到 72% 后 4×72+18 > 280，第 4 列（剧情）被裁掉。
   改成 `grid-template-columns: repeat(4, minmax(0, 1fr))` + `.app-icon { padding: 0; min-width: 0 }` + 图标 `width: min(60px, 100%)`。

`round6.mjs` 实测：标题 `y=270 / 305px / 96px`，金币 `rgba(4,36,48,.78)` + `rgba(44,228,252,.2)` + `5px`，手机 `310×684 / top 216 / ratio .72×.76`；`uiall` 七个 App 在窄屏下均无溢出。
