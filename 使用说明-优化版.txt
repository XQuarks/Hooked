一钩上天 · GitHub Pages / 手机适配 Release 版

本机试玩：完整解压后双击“启动网页版.cmd”。结束后可用“停止本地服务.cmd”关闭本地服务。不要直接双击 index.html。

GitHub Pages 更新：把本文件夹内的 index.html、index.js、index.wasm、index.pck、index*.png、音频 worklet 的 .js 文件、audio-credits.txt 和 .nojekyll 放到网站的同一目录。不要改这些文件的名称。所有路径都是相对路径，可用于 /Hooked/ 这样的项目子目录。

这是 Release 单线程版本，不依赖 SharedArrayBuffer 或 COOP/COEP 特殊响应头。GitHub Pages 会对引擎和游戏资源启用 gzip。代码、字体和资源已按网页实际用途裁减，不需要额外的压缩加载脚本或服务工作线程。

主要修正：
- 标题保持显示，分帧准备资源并预绘制海面、水下与高空；准备完毕后才开始淡出标题、下移镜头，准备中轻触不会绕过加载。
- 全部运行音乐与音效替换为魔王魂/森田交一、Kenney 的免费许可素材，保留鸣谢和逐文件出处。声音预缓存，最多8路音效与2路音乐，切换有淡入淡出。
- 天空随实际镜头高度变化：海湾云层、薄云与飞机、高空星星/月牙，另有极地极光与各海域配色；一个不透明绘制通道，无体积云和星星粒子。
- 网页专用透明水面，避免把屏幕图像叠加到高亮发光通道造成白色爆光。
- 网页灯光单独校正；桌面 Forward+ 的灯光和原素材保留。
- 水花按实际相机射线定位，修正原先约 11～24 像素的投影错位。
- WebGL 使用程序透明光束，替代不受支持的体积雾着色器。
- 绘制尺寸上限为540像素宽、1134像素高，仍按手机长宽比和安全区适配。
- 中文字库保留当前全部游戏文本的字形；旧字体文件不修改。编辑中文内容后，请重新运行 tools/web/export_pages.ps1，自动重新生成字库子集。

进度存储：网页进度使用浏览器本地存储，与桌面存档独立。请尽量用相同浏览器与网址持续游玩。

兼容范围：需支持 WebAssembly 和 WebGL 2.0 的现代浏览器。网页光效已做适配，体积雾、环境遮蔽、景深与桌面版仍有区别。安卓真机的网络、GPU驱动和浏览器差异需在手机上复测。
