# 03 · 功能增删清单

> **概述**：基于 02 文档的诊断，把原 demo 的每一项功能归入「保留 / 优化 / 新增 / 删除 / 延期」五类，并给出理由、实现成本、风险与验收标准。这是重制的范围契约。
> **状态**：已完成，重制实现按本清单执行。
> **读者**：实现者、验收者。
> **关联**：`02-问题诊断与优化点.md`（问题来源）、`04-重制方案与关键取舍.md`（如何实现）。

---

## 0. 判定原则

1. **只保留服务核心循环或叙事的系统**，其余一律降级或删除。
2. **新增功能必须解决 02 文档里的某条 P0/P1**，不做「因为炫」的功能。
3. **任何删除都不删除「内容」（文案、鱼种、剧情）**，只删除「容器」（多余的 APP、重复的入口）。
4. 成本用 **S/M/L** 表示（S < 半天，M ≈ 1 天，L > 1 天）。

## 4. 删除 / 降级

| 功能 | 处理 | 理由 | 内容去向 |
|---|---|---|---|
| 「加金币」APP | **删除** | 直接摧毁经济（D-09） | 无（开发模式保留 `?dev=1` 一次性入口） |
| 设置页里的「一键加 10 万」 | **删除** | 同上，且重复入口 | 无 |
| 「海况天气」APP | **删除** | 纯文本装饰，信息可由 HUD 深度带徽标承担 | 关键文案并入深度带名字 |
| 「鱼市行情」APP | **合并** | 与图鉴信息重叠 80% | 价格表进图鉴；新闻 3 条进鱼博 |
| 「漫画」独立 APP | **合并** | 只是 4 部静态漫画，不值得占一个入口 | 并入「剧情」页（短信顶部 Tab） |
| 「鱼博」独立 APP | **保留但降级** | 社交信息流是叙事载体，但交互极浅 | 保留，缩为 1 屏信息流 |
| Canvas HUD | **删除** | 与 DOM HUD 重复（D-13） | 全部 DOM 化 |
| emoji 装饰（锚/购物车/摩天/企鹅…） | **替换** | 跨平台不一致（D-11） | 3D 低模道具 + 少量贴图文字牌 |
| 皇冠（$20,000） | **删除** | 极端价格只为延长曲线（D-02） | 收益并入「渔夫徽章」系列（3 档） |

| `scenery.ts` 2D 天空/海床 | **删除** | 3D 场景替代 | — |
| 副标题「RIDICULOUS FISHING 复刻版」 | **改写** | 避免直接蹭名 | 改为「荒唐钓鱼 · 深海重制版」 |

**净变化**：APP 13 → 8，代码模块 16 → 约 14（但体积上升，因 3D 渲染），UI 入口减少 5 个，作弊入口 2 → 0。

## 5. 延期（本次不做，写清原因避免反复讨论）

| 功能 | 原因 | 触发条件 |
|---|---|---|
| 第三张地图（深海裂谷） | 需要 8+ 新鱼、新机制、新剧情线，成本 > 本次全部 UI 改造；且会稀释两张图的密度 | 前两张图留存达标后再评估 |

| 鱼竿/鱼线皮肤系统 | 不影响玩法，纯外观；帽子已覆盖个性化需求 | 后续赛季化 |

| 关卡编辑器 | 与随机深度轴的设计冲突 | 不做 |

## 6. 验收清单（重制版必须逐条通过）

- [ ] 竖屏 9:16 下，单手（拇指）可完成下潜、收线、射击全流程
- [ ] 下潜阶段存在至少一个「主动放弃深度」的操作
- [ ] 空中每条鱼都能在 0.5s 内被判断出「值不值 / 打几枪」
- [ ] 连杀有可见倍率与音画反馈
- [ ] 三档画质在中端设备上分别 ≥ 30 / 45 / 60fps（以帧时间中位数计）
- [ ] 从零到通关 < 25 局；全满 < 60 局
- [ ] 旧存档（v1 key）可迁移，不丢已解锁内容
- [ ] 刷新页面、切后台回来，剧情队列不丢、不重播
- [ ] 无任何作弊入口出现在正常 UI 中
- [ ] 全站无外部资源请求（离线可玩）
