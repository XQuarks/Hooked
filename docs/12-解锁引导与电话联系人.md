# 12 · 功能解锁节奏、解锁引导与电话联系人

> **概述**：这一轮解决三个问题：①功能解锁没有节奏、玩家不知道新开了什么；②解锁之后没人告诉你去哪点；
> ③电话 App 只有一串流水账，看不到「这个人跟我聊过什么」。现在解锁按趟数分四段，每段都有一个角色打电话/发短信点名新功能；
> 电话 App 变成「联系人 → 历史通话（含整段对话）」。
> **状态**：**已实施**（2026-10-23）。`unlock.mjs` 全绿；`smoke / split / notify / ui / fix5 / play / round6` 无回归。
> **读者**：接手这个项目的开发者、写剧情的人。不需要读源码也能照着加一条解锁引导。
> **关联**：`08-流程与解锁优化方案.md` §9.3（原来的分阶段解锁表）、`rebuild/src/game/state.ts`（`appUnlocked` / `logCall`）、
> `rebuild/src/game/story.ts`（事件表）、`rebuild/src/ui/apps.tsx`（`CallsApp`）。

## 1. 解锁节奏：四段，每段 1–2 个

| 趟数 | 新开 | 为什么放这儿 |
| --- | --- | --- |
| 0 | 短信 / 电话 / 剧情 / 鱼鉴 / 设置 | 开局 5 个图标，够用，不吓人 |
| 1 | 鱼博 + 渔具 | 第一趟回来正好有钱、有战报，也需要升级鱼线才能更深 |
| 2 | 枪铺 + 档案 | 玩家已经知道「打鱼」是什么，开始关心「怎么打得更狠」 |
| 3 | 航线 | 中期给一个长线目标：北边那片海 |
| 4 | 帽子 | 纯装饰，放最后，当彩蛋 |

锁定态仍然是「灰图标 + 🔒」，点一下给出具体条件。**这次唯一的数值改动**是把航线的条件从
「下潜 40 米 **或** 3 趟」改成「只看 3 趟」——实测第一趟就能潜到 40 米，航线等于开局就有，
中期内容被提前消耗。

## 2. 解锁引导：每段都有人开口

系统通知（岛上那条「新应用 ×N」）只说明「多了个图标」，不解释「它有什么用」。所以每段再补一条人情味消息：

| 事件 id | 条件 | 形式 | 说话人 | 说了什么 |
| --- | --- | --- | --- | --- |
| `introAfterFirst` | 第 1 趟 | 来电 | 翠花姐 | 原有台词里加一句：「今天多了两个图标：鱼博看别人吹牛，渔具店花钱。先点渔具店，你那条线细得像挂面。」 |
| `unlockGuns` | 第 2 趟 | 来电 | 大炮哥 | 「手枪打一条，霰弹枪打一片，自己算账。」+ 顺带解释「战绩」为什么记亏钱 |
| `unlockRoute` | 第 3 趟 且 还没解锁冰海 | 来电 | 王镇长 | 「北边那片冰海，航线上给你留了个位置。潜到 180 米、认识 8 种鱼，那片海就会亮起来。」 |
| `unlockHat` | 第 4 趟 | 短信 | 老妈 | 「你三婶给你织了几顶帽子……手机里那个「帽子」能换着戴。」 |

设计原则：

- **重要功能用电话，装饰用短信**。电话会冻结画面、必须处理；短信躺在手机里，等玩家自己发现。
- **引导必须说「在哪、为什么」**，不能只说「解锁了新功能」。
- 说话人要对得上人设：渔具店老板娘推荐渔具店、枪铺老板推荐枪铺、镇长管航线、老妈只会寄东西。

## 3. 电话 App：联系人 + 历史对话

### 3.1 数据结构

`CallLog` 新增 `lines`：

```ts
export interface CallLog {
  id: string;        // 'call_' + 队列 uid
  from: CharId;
  topic: string;
  trip: number;
  missed: boolean;
  lines?: { me?: boolean; text: string }[];   // 新增：整段对话
}
```

`logCall()` 多一个 `lines` 参数；**漏接 → 回拨接听**时会挂回原来那条记录（`id` 相同），
把 `missed` 改成 `false` 并把台词补上——以前这条分支只改 `missed`，
回拨过的电话在联系人里仍然写着「这通电话没有留下记录」。

回拨产生的通话没有队列 uid（`cb_<时间戳>`），结束时用「这个人最近一条记录」的 id 落库，
所以**反复回拨不会堆出一串重复记录**。

### 3.2 界面

| 层级 | 内容 |
| --- | --- |
| 列表 | 联系人 = 打过电话的 ∪ 发过短信的（漂流瓶、自己除外），按最近一趟排序；副标题是最后一次通话主题或最后一条短信；右侧显示未接数 / 通话次数 / 「短信」 |
| 详情 | 头像 + 名字 + 身份；两颗按钮「回拨」「发短信」；下面是这个人的每一次通话卡片 |
| 通话卡片 | 主题 + 第几趟；未接的写「未接听 · 点上面回拨打回去」；接过的按聊天气泡铺开整段对话 |

样式从旧的米黄 + 深橄榄（2010 年功能机味）改成白卡 + 浅灰底 + 蓝色拨号按钮，和系统短信一个调子。
