# 02 · 问题诊断与优化点

> **概述**：对原 demo 做结构化体检，输出 24 条带严重度、源码证据、影响面与修复方向的问题清单，并给出「哪些是必须动结构的、哪些只是打磨」的判断。
> **状态**：已完成。结论基于 `old/src/**` 逐行阅读 + 数值代入估算。
> **读者**：决定重制范围的人 / 实现者。
> **关联**：`01-原demo结构梳理.md`（结构基线）、`03-功能增删清单.md`（据此产出取舍）。

---

## 0. 评估维度与判定标准

| 维度 | 关注点 | P0 判定 |
|---|---|---|
| 核心手感 | 下潜/收线的决策密度、射击反馈 | 玩家 3 局内会感到「无聊」或「不公平」 |
| 结构深度 | 重复可玩性、地图/流派差异 | 内容 30 分钟内见底，或存在严格上位替代 |
| 可读性 | 信息层级、状态可见性 | 玩家不知道自己在赚什么/亏什么 |
| 平衡 | 收益/成本曲线、负反馈强度 | 后期数值失去意义，或前期劝退 |
| 性能 | 帧内分配、绘制调用、移动端 | 中端手机掉到 45fps 以下 |
| 内容 | 文本量、系统数量与核心循环的配比 | 附属系统比核心玩法更重 |
| 移动端 | 竖屏适配、触控、安全区 | 单手不可玩 / 刘海遮挡 |

## 2. 关键问题的量化论证

### 2.1 D-02：养成曲线 vs 内容消耗

| 阶段 | 累计支出 | 需要出海次数（按该阶段单局收益） |
|---|---:|---:|
| 前 3 级鱼线 + 2 级钩 | ~$700 | 约 8 局（$40→$120/局） |
| 解锁冰海（线 4 级 + 船票） | ~$5,520 | 约 6 局（$300~800/局） |
| 冰海头灯 + 防流鳍满级 | ~$25,600 | 约 12 局（$800~2000/局） |
| 全部枪械 | ~$48,300 | 约 25 局 |
| 全部帽子（含皇冠 $20,000） | ~$73,400 | 约 40 局 |
| **全满** | **~$121,750** | **约 100~150 局** |

而剧情终点（鱼王 + 终章漫画）在第 20~30 局即可达成。**通关之后是 4~6 小时的纯数值刷取**，且没有任何新机制注入。

> 重制判断：不应靠「把价格调低」解决，而应**同时**做三件事——压缩总需求、给后期注入新变量（深度带行为差异 / 连杀倍率 / 终局挑战）、让旧地图有回访理由。

### 2.2 D-03：下潜段的决策密度

原版下潜 12~16 秒，玩家每帧只有「左/右」一个自由度，唯一决策是「绕开鱼」。可用决策点统计：

| 决策类型 | 原版 | 说明 |
|---|---:|---|
| 路径选择（绕行） | ✅ | 唯一决策 |
| 深度目标（贪多深） | ❌ | 没有「主动停止下潜」的手段，深度由「是否撞鱼」被动决定 |
| 资源消耗（氧气/子弹） | ❌ | 无 |
| 风险交换（撞鱼换收益） | ❌ | 撞鱼必然是终止，不能换 |
| 收集支线（漂流瓶） | ⚠️ | 有，但位置随机且无代价，纯白送 |

> 重制判断：给「下潜」加一个**主动放弃深度换安全**的出口，或让「深度」与「收线段的可钩数量」形成张力。最小改动是：允许长按上浮（提前结束下潜，保住已得），并在 HUD 实时显示「若现在上浮预计收入」。

### 2.3 D-10 / D-11：帧内成本抽样

| 每帧操作 | 次数（估） | 问题 |
|---|---:|---|
| `createLinearGradient` | 2~4 | 水体 + 天空（8 段 stop）+ 海床 |
| `createRadialGradient` | 1~8 | 每个发光装饰、每个漂流瓶 |
| `ctx.fillText(emoji)` | 5~30 | 装饰、企鹅、鱼种飘字 |
| `Array.filter`（粒子） | 1 | 每帧新数组 |
| 全屏合成 | 2 | 主 canvas + 黑暗 canvas 的 `drawImage` |

在桌面无感，在中端 Android（尤其 2x DPR）上是可测的抖动来源。**重制的渲染必须换成「一次性建资源 + 逐帧只更新 uniform」的模式。**

### 2.4 D-01：地图上位替代的数学

| 指标 | 阳光湾 | 极光冰海 |
|---|---|---|
| 单条均价值（全部鱼加权） | ≈ $15 | ≈ $52 |
| 最大深度 | 400m | 600m |
| 单局可钩上限（满级） | 40 | 40 |
| 单局理论收入 | ≈ $600 | ≈ $2,080 |
| 独占机制 | 金鱼 $300（60% 概率） | 鱼王 $1000（通关） |

冰海在收益上是 3.5 倍，且通关后**没有任何理由回阳光湾**——除了「金鱼」。这是设计层的浪费，不是数值问题。

## 3. 优化点分级：必须动结构 vs 只需打磨

### 3.1 必须动结构（P0，重制时无法通过调参解决）

1. **地图差异化**：给每张地图一个**独占资源**（阳光湾 = 高频小额 + 漂流瓶线索；冰海 = 高压高风险 + 鱼王），并让「热门鱼」按地图独立刷新，使回访有利可图。
2. **深度带（biome）**：把一条深度轴切成 4~6 个「带」，每带在**光照、能见度、鱼行为、道具**上都有可感知变化，让「下潜」本身成为观光与压力并存的旅程。
3. **空中阶段的信息化**：目标必须自带「价值 + 血量 + 威胁」三重可读信息（3D 场景可用鱼体发光/描边/标签分层实现）。
4. **负反馈重新定价**：罚款应按「本局预期收益」比例缩放（如 15%），而不是固定 $20。

### 3.2 只需打磨（P1，可在重制版直接改掉）

- 连杀倍率（0.9s 内连续击杀 → ×1.1 叠乘，上限 ×2.5）
- 拔枪/换弹节奏（自动武器加 1.2s 过热）
- 触控偏移（鱼钩渲染位置比手指高 24px）
- 安全区 + 单手模式
- 结算去重（水母只出现在罚款行）
- 提示系统（首次遇到某机制时弹一次气泡，不再绑定 `trips<3`）
- 暂停 / 中途上浮 / 实时预估收益
- 存档版本号 + 导出导入

### 3.3 可以砍（P2/P3，见 03 文档）

- 加金币 APP、天气 APP、漫画独立 APP、鱼市独立 APP
- Canvas HUD（并入 DOM 层）
- 每帧 emoji 装饰（换 3D 道具或预渲染精灵）

## 4. 三条「不要改」的底线

重制最容易犯的错，是把原版真正好的东西一起改掉：

| 底线 | 原因 |
|---|---|
| **「下潜撞鱼=结束，收线撞鱼=收益」的双义碰撞** | 这是全游戏最聪明的规则，任何「下潜撞鱼也加分」的改动都会摧毁张力 |
| **「没打死就被打得更高」的荒谬感** | 它是「荒唐」二字的来源，也是操作失误的幽默转化器，不要改成普通扣血 |
| **叙事包裹重复劳动** | 短信/公告/漫画把刷钱变成追查爷爷，是留存的核心；砍叙事去换玩法深度是净亏 |

---

## 5. 诊断结论（给重制的一句话）

> 原版是**一个手感成立、叙事有梗、但结构只做了半套**的垂直切片：核心循环的「动作」够了，「决策」不够；内容量够读，「内容寿命」不够长；画面风格统一，但「光影」是画出来的不是算出来的。
>
> 重制的正确姿势不是「加更多内容」，而是**换一套能承载光影的渲染底座（3D）+ 给深度轴注入行为差异 + 收敛附属系统 + 重做经济曲线**。
