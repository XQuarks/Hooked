## 0. 一句话规则

> **改数值 → 只改 `src/config.js` → 跑 `node .dev/gen-docs.mjs` → 文档自动同步。**

不要在文档里手写数字。历史上一共抓到 **6 批**「文档写着旧值、代码其实是新值」的漂移
（鱼数 9→18、地图 1→2 张、升级 5→11 项、灯具铜位、起飞曲线、
**许可证退役后仍写着"拿到许可证才上架"**……），全部源于手抄副本。

⚠ 最新一批（2026-09-18）**连生成器也救不了**：它只覆盖 `docs/01~06`，
而 `README` / `GAMEPLAY` / `STRUCTURE` / `EXPANSION` 是手写的 ——
**改 `config.js` 时，这四份必须回头人读一遍。**

## 2. 「想改什么 → 改哪里」速查

| 想改的东西 | 改哪里（`src/config.js` 里的常量） |
|---|---|
| 鱼的身价 / 血量 / 体型 / 出现权重 | `SPECIES[]` 对应条目 |
| 加一种新鱼 | 往 `SPECIES[]` 加一条（用 `zones` 指定它出现在哪些海域） |
| 稀有度概率与倍率 | `RARITY[]`（⚠ 概率之和必须 = 1） |
| 每层刷几条鱼 | `FISH_DENSITY` |
| 海域的深度区间 / 名字 | `ZONES[]` |
| 加一张新地图 | `MAPS[]` + `ZONES[]` 加它的 5 个海域 + `MAP_LEVEL_CAP` 加一档 |
| 升级项的名称 / 基础价 / 分组 | `UPGRADES` + `UPGRADE_ORDER` |
| 升级每级给多少 | `LEVELS`（⚠ 索引 0~4 已冻结，别动） |
| 成长速度（多久升满） | `GROWTH` |
| 地图的等级闸门 | `MAP_LEVEL_CAP` |
| **枪械的伤害 / 范围 / 射速 / 弹匣** | `GUNS[]` 对应条目的 `dmg` / `rad` / `cd` / `mag` / `reload`（每项 6 档） |
| **加一把新枪** | 往 `GUNS[]` 加一条 + 在 `src/icons.js` 的 `GLYPH` 里加同名 `icon` |
| **枪械升级价格** | `GUNS[].upBase` + `GUN_GROWTH` |
| ~~「攻击力」这项升级给多少~~ | **已在 v0.5 删除** —— 攻击力并进了 `GUNS[].dmg`（见 [`06-枪械.md`](./06-枪械.md)），`LEVELS` 里已经没有 `gunPower` |
| 下潜 / 收线 / 抛竿手感 | `TUNING` |
| 深海黑暗与灯具 | `DEEP` + `LEVELS.lampRadius / lampPower` |
| 浮冰 | `ICEBERG` |
| 鱼的一句话说文 / 地图简介 | `SPECIES[].desc` / `MAPS[].desc` —— 然后重跑生成器 |

## 3. 生成器用法

```bash
node .dev/gen-docs.mjs           # 生成 / 覆盖 01~06
node .dev/gen-docs.mjs check     # 只校验不写盘：与 config.js 不一致则退出码 1
```

- 生成的文件开头都带 `<!-- AUTOGENERATED ... -->` 标记，**手改会在下次生成时被覆盖**。
- 想改文案（比如给某条鱼换个说法），**改 `config.js` 里的 `desc`**，不要改文档。
- 生成器**只写这 6 个文件**，不碰 `README.md` / `DESIGN.md` / `STRUCTURE.md`。

## 4. 为什么这样拆

| 原来（手抄副本） | 现在（生成） |
|---|---|
| 同一个数字散落在 README、DESIGN、config 三处 | 只有 `config.js` 一处，文档是投影 |
| 改了代码忘了改文档 → 文档骗人 | `gen-docs.mjs check` 一跑就知道 |
| 改数值要翻好几份文档 | 只翻 `config.js`，然后重跑 |
| 数值和叙事混在一起，调数值容易误伤文案 | 数值（01~04）与叙事（05）分开 |

**分工约定**：

- `README.md` —— 面向**玩家**：怎么玩、怎么部署。**不放大表**，需要数据时链接到 `docs/`。
- `DESIGN.md` —— 面向**开发**：为什么这样设计、迭代 1~10 的踩坑记录。
  **现值表不再抄录**（2.5 节只留设计意图与公式，完整数值链接到本目录）；
  迭代记录里的历史数字**保持原样**（是当时的快照，不是现值）。
- `EXPANSION.md` —— 面向**未来**：扩建方案与路线。
- `docs/` —— **唯一的数值与文案参考**，全部生成。
